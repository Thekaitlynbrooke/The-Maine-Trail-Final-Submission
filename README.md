# Final Project Starter
 
Starter files for CIS333 Final Project. Please replace this text with a description of your final project, including your name, the project specifications, and anything that your instructor needs to know to run it.

The index.php file is the main landing page for your project and currently uses Bootstrap to get you started. You can (and should) add additional files as needed and are not required to use Bootstrap - feel free to remove it.
